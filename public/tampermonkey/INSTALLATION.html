🎭 Script Tampermonkey

Installation guidée pour Nexus-Tauri

1

Installer Tampermonkey

Installez l'extension Tampermonkey pour votre navigateur :

🌐 Chrome 🦊 Firefox 🔷 Edge 🍎 Safari
2

Installer le script

Cliquez sur "📥 Installer" pour le script :

📦 Script disponible

Nautiljon Extractor (Lectures VF) 📚
Extrait automatiquement les données des mangas et light novels depuis Nautiljon (édition française uniquement). Récupère le titre, synopsis, genres, thèmes, métadonnées complètes et liste des volumes VF avec leurs dates de sortie. Deux modes disponibles : Import complet (📚) pour créer une nouvelle entrée, ou Import tomes (📖) pour ajouter uniquement les volumes à une série existante.
📥 Installer
⚠️ Important : Nexus-Tauri doit être lancé pour que le script fonctionne (serveur d'import sur port 40000).
✅ Astuce : Vous pouvez aussi glisser-déposer le fichier .user.js directement dans votre navigateur pour une installation encore plus rapide !
3

Vérifier l'installation

Pour vérifier que le script est bien installé :

  • Cliquez sur l'icône Tampermonkey dans votre navigateur
  • Sélectionnez "Tableau de bord"
  • Vous devriez voir le script "Nautiljon → Nexus-Tauri (Lectures VF)" dans la liste
  • Assurez-vous que le script est activé (interrupteur vert à côté du script)
4

Utiliser le script

Le script s'active automatiquement sur les pages Nautiljon compatibles :

  • 📚 Nautiljon (Mangas & Light Novels) : Deux boutons apparaissent en bas à gauche de la page
  • 📚 Import complet : Extrait toutes les données (titre, synopsis, métadonnées, volumes VF). Récupère automatiquement les dates de sortie en visitant chaque page de volume. Les données sont ensuite envoyées vers Nexus-Tauri où vous pourrez choisir vers quelle entrée de votre bibliothèque les importer.
  • 📖 Import tomes : Extrait uniquement la liste des volumes VF avec leurs dates de sortie. Utile pour mettre à jour une série déjà existante dans votre bibliothèque.
  • 🔍 Logs détaillés : Ouvrez la console du navigateur (F12) pour voir tous les détails de l'extraction en temps réel.
5

Finaliser l'import dans Nexus-Tauri

Après avoir cliqué sur un bouton d'import sur Nautiljon :

  • ⏳ Une notification apparaît sur Nautiljon confirmant l'envoi des données
  • 📥 Nexus-Tauri affiche automatiquement une modale de réception
  • 📋 La modale liste toutes vos fiches de lecture existantes
  • 🔍 Vous pouvez rechercher par titre ou ID MAL
  • ✅ Sélectionnez la fiche cible et cliquez sur "Appliquer l'import VF"
  • 🎉 Les données Nautiljon sont fusionnées avec votre fiche et les volumes sont créés/mis à jour
